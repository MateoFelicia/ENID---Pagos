FALTA ACTUALIZAR LA BASE DE DATOS

La web está instalada, pero la base de datos todavía no tiene las tablas de esta versión. Quien administra el sitio tiene que correr, en la carpeta del proyecto:

python -m flask db upgrade

Si ese comando muestra el error «Multiple head revisions», hay un archivo de migración de más en migrations/versions: corré python -m flask db heads para ver cuáles son.

El detalle exacto está en la consola donde corre el servidor. Después de actualizar, recargá esta página.
